# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Repo Is

A collaborative, documentation-first learning repo for frontend developers working through a roadmap (HTML → CSS → JavaScript → React). There is no build system, package manager, or test runner — all work is plain HTML, CSS, JS, and Markdown notes.

## Repository Structure

- `HTML/`, `CSS/`, `JAVASCRIPT/`, `REACT/` — topic folders; each contains an `index.md.txt` with the learning prompt/task description for that topic.
- `CONTRIBUTORS/<name>/` — each contributor's personal folder. Contains their `index.md.txt` (their current project prompt) and `resume.png` (their project screenshot reference). Contributors only push work inside their own folder.
- `PROJECTS/` — shared mini-projects folder for completed work.

## Contribution Rules

- Each contributor works only inside `CONTRIBUTORS/<their-name>/` unless explicitly collaborating.
- Changes to shared topic folders (`HTML/`, `CSS/`, etc.) or `PROJECTS/` should go through a Pull Request.
- Commits should be clean and meaningful.

## Current First Project (all contributors)

Build a single-page HTML CV using only HTML. Requirements:
- Semantic HTML structure
- SEO meta tags
- Favicon or Font Awesome icon
- Should visually match the `resume.png` reference image in the contributor's folder
