# frontend-roadmap-journey

📚 A collaborative learning repo for frontend devs — guided by a teacher, built by students.

---

## 📁 Structure

```
CONTRIBUTORS/<your-name>/   → Your personal workspace
HTML/                       → HTML topic prompts
CSS/                        → CSS topic prompts
JAVASCRIPT/                 → JavaScript topic prompts
REACT/                      → React topic prompts
PROJECTS/                   → Shared mini-projects
```

---

## 🗺️ Roadmap

Students progress through topics in this order:

1. **HTML** — Semantic structure, SEO, accessibility
2. **CSS** — Styling, layouts, responsiveness
3. **JavaScript** — DOM, logic, interactivity
4. **React** — Components, state, modern frontend

Each topic folder contains a prompt (`index.md.txt`) with the task and requirements.

---

## 🚀 Getting Started (Students)

1. **Fork** this repo on GitHub
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/frontend-roadmap-journey
   ```
3. Work on your tasks inside `CONTRIBUTORS/<your-name>/` (your folder is already set up for you)
5. **Push your changes** and open a **Pull Request** for feedback

---

## ✅ Rules

- Work only inside `CONTRIBUTORS/<your-name>/` unless collaborating
- Keep commits clean and meaningful (e.g. `Add HTML CV structure`)
- Submit work via Pull Requests — feedback happens there
- To get the latest prompts from the main repo:
  ```bash
  git remote add upstream https://github.com/gekkin-programmer/frontend-roadmap-journey
  git pull upstream main
  ```
